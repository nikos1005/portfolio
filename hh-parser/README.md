# 📊 HH.ru Парсер вакансий

Бот/скрипт для сбора вакансий с hh.ru по запросу.

## Возможности:
- Парсит вакансии по ключевому слову
- Сохраняет в CSV/Excel
- Фильтрует по зарплате, опыту
- Можно запускать по расписанию

## Использование:

```bash
# Установка
pip install requests beautifulsoup4 pandas

# Запуск
python3 parser.py --query "python разработчик" --city "Москва" --output vacancies.csv
```

## Параметры:
- `--query` — поисковый запрос (например, "Python Django")
- `--city` — город (Москва, СПб и т.д.)
- `--salary` — минимальная зарплата (фильтр)
- `--output` — файл для сохранения (CSV)

## Пример вывода:
```
Найдено 50 вакансий
Сохранено в vacancies.csv

Формат:
Название | Компания | Зарплата | Ссылка
```
