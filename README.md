### 2. 📊 Парсер вакансий hh.ru
**Ссылка:** `hh-parser/`

**Что делает:** Собирает вакансии с hh.ru по запросу, фильтрует, сохраняет в CSV/Excel.

**Технологии:**
- `requests` + `BeautifulSoup4` — парсинг
- `pandas` — анализ и экспорт
- `argparse` — CLI

**Возможности:**
- Поиск по ключевым словам
- Фильтрация по городу, зарплате
- Сохранение в CSV/Excel
- Статистика (средняя зарплата)

**Для заказа:** Сделаю парсер любого сайта (авито, Avito, Wildberries, LinkedIn) с сохранением в нужном формате.
